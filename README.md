# 手順ノート

手順書を検索・閲覧・編集できる日本語のシンプルなWebアプリです。

- キーワード検索、カテゴリ絞り込み、お気に入り
- ステップごとの詳細説明・注意点
- 手順書の追加と編集
- スマートフォン対応

## 起動

`index.html` をブラウザで開くか、静的Webサーバーで配信してください。ビルドや依存パッケージのインストールは不要です。

## GitHub Pages

リポジトリの Settings → Pages → Source で **GitHub Actions** を選択してください。
`main` へのpushで `.github/workflows/pages.yml` がサイトをデプロイします。

## データ保存

手順書とお気に入りは各ブラウザのlocalStorageに保存されます。チーム間・端末間の同期はありません。
Sites版とGitHub Pages版ではURLが異なるため、Sites版に保存したデータは自動移行されません。
サンプルの手順は実際の社内ルールに合わせて編集してください。
